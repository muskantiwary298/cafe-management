# ☕ Cafe Management System

A modern and responsive Cafe Management System built using HTML, CSS, and JavaScript. This project helps manage cafe orders, menu items, customer billing, and sales through a simple and user-friendly dashboard.

## ✨ Features

- 📊 **Dashboard** – View total sales, today's orders, and menu items.
- ☕ **Cafe Menu** – Browse coffee, tea, snacks, desserts, and drinks.
- 🔍 **Search & Filter** – Find items by name or category.
- 🛒 **Shopping Cart** – Add items and manage quantities.
- 🧾 **Automatic Billing** – Calculate subtotal, demo GST, and total amount.
- 👤 **Customer Details** – Enter customer name before placing an order.
- 🖨️ **Print Bill** – Generate and print customer receipts.
- 📋 **Order History** – View recent orders and their bills.
- 💾 **Local Storage** – Save order history in the browser.
- 📱 **Responsive UI** – Designed for desktop, tablet, and mobile screens.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/cafe-management-system.git
```

### 2. Open the Project

```bash
cd cafe-management-system
```

Open this folder in Visual Studio Code.

### 3. Run the Application

1. Install the **Live Server** extension in VS Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.
4. The Cafe Management System will open in your browser.

No additional backend or database installation is required.

## 📖 How to Use

1. Browse the cafe menu.
2. Search for products or select a category.
3. Add items to the cart.
4. Increase or decrease item quantities.
5. Enter the customer's name.
6. Click **Place Order & Generate Bill**.
7. View or print the generated receipt.
8. Check recent orders in the Order History section.

## ⚠️ Limitations

- This is a frontend demo project.
- Order history is stored in browser Local Storage.
- Data is not synchronized between devices.
- GST is set to 5% for demonstration and should be adjusted according to applicable tax rules.
- Secure authentication and database integration are not included.
